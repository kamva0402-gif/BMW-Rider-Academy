# BMW Motorrad Rider Academy — Simple Website

This version is designed to be easy to maintain.

## The only folders you need to worry about

### `images/`
Put website pictures and logos here.

### `videos/`
Put your Rider Academy videos here when they are ready.

## Changing a picture

1. Open the `images` folder.
2. Replace the existing picture with your new picture.
3. Keep the SAME filename.
4. Upload/save the change.
5. The website will use the new picture.

For example:

`images/phase2-training.jpg`

Replace that file with another image using the same filename.

## Changing a video

When videos are ready, put them in `videos/`.

Recommended names:

- `basics-of-bike.mp4`
- `what-to-wear.mp4`
- `how-training-works.mp4`
- `learners-licence.mp4`
- `riding-licence.mp4`

## Website pages

- `index.html` = Landing page
- `phase1.html` = Phase 1
- `phase2.html` = Phase 2
- `phase3.html` = Phase 3

## Important

You do NOT need to understand all the HTML to maintain the site.

Start by learning only:
1. How to replace an image
2. How to replace a video
3. How to change a link

We can learn the rest as you need it.
